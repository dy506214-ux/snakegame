# Professional Snake Game in Python

A fully featured, desktop responsive Snake game built with Pygame.

## Features

- **Professional Graphics**: Detailed snake rendering with head, eyes, mouth, fading body segments, and tail
- **Eating Food**: Snake grows when consuming food (goli)
- **Background Music**: Procedurally generated ambient music
- **Sound Effects**: Eat sound when consuming food
- **Desktop Responsive**: Windowed mode with resizable window
- **Fullscreen Toggle**: Press ESC to toggle fullscreen
- **Particle Effects**: Golden particles when eating food
- **Scoring System**: Score increases with each food eaten
- **Levels**: Speed increases every 200 points
- **High Score**: Persistent high score saving
- **Game States**: Menu, Playing, Paused, Game Over
- **Smooth Controls**: Arrow keys for movement
- **Menu Bar**: Professional top menu bar with title
- **Bordered Play Area**: Snake and food confined within bordered boxes
- **Dynamic Background**: Background color changes every time food is eaten

## Controls

- **Arrow Keys**: Move snake
- **Space**: Start game from menu
- **ESC**: Toggle fullscreen / Pause game
- **R**: Restart after game over
- **M**: Return to menu after game over

## How to Play

- Use arrow keys to control the snake within the bordered play area
- Eat the red food to grow, increase score, and change the background color
- Avoid hitting walls or yourself
- Game speeds up as you progress through levels

## Requirements

- Python 3.x
- Pygame
- NumPy (optional, for audio generation)

## Installation

1. Install Pygame:
   ```bash
   pip install pygame
   ```

2. Install NumPy (recommended for audio):
   ```bash
   pip install numpy
   ```

## Running the Game

```bash
python snake_pro3.py
```
